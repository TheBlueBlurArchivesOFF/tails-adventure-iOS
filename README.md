<h1 align="center">
  Tails Adventure Remake
</h1>

Tails Adventure is a Sonic the Hedgehog spin-off game, released for the Sega Game Gear and featuring Tails in a solo role. As opposed to other Sonic titles with fast-paced gameplay, Tails Adventure is a Metroidvania-styled game with emphasis on exploration, collecting items and backtracking. It's a unique "hidden gem" of the series that couldn't get attention it deserves due to low popularity of Game Gear.

This release features a port of Tails Adventure Remake by Mechakotik, ported to iPhone devices. Here's what changed in the remake:
- **Balance changes:** Featuring rebalanced gameplay, enemies and bosses, to make the game more challenging.
- **QoL improvements:** Includes more responsive controls, a pause menu, item hotswap (changing any items you already own without going to Tails' House) etc.
- **Display support:** The game runs in any resolution and refresh rate, displays subpixels, and allows for adjusting internal resolution to "zoom out the camera".
- **Input support:** Features support for keyboards, gamepads/controllers & touchscreen inputs, as well as support for rumble and an analog stick.
- **Main Menu & Save System:** Booting up the game presents a Sonic 3-styled main menu with a data select, settings, and random tiny quotes that change every time you enter.

Alongside everything that the remake offers, the iOS port includes some neat exclusive features:

- **In-Built Achievements:** Featuring all 46 achievements from the *RetroAchievements* list, you can complete these as you play through the adventure. All 46 of them can be viewed in the Main Menu via the Achievements button. Please note that some of the achievements are not possible to complete yet!
- **Touch Screen Sliders:** You can customise the size and opacity of the touch controls by going to Settings > Touch.

## Completion status

The game is fully playable and can be completed 100%. However, a few non-essential features from the original game are still missing:

- Items: Wrench, Sonic, Item Radar
- *Most* in-game cutscenes
- Hover pod bullet and fire attacks
- Tails idle animation
- Helmet rotated frames

## OG Releases & Testing

The original binary releases for Windows, Android and Linux (amd64) are available at [Releases](https://github.com/mechakotik/tails-adventure/releases). 

This port has been so far ONLY tested on an iPhone 16 base model, with 128GB memory and iOS27 installed. Previous models and versions of the OS should work just fine, but we reccomend that everything is up to date. Like every iOS app currently, this is a 64-bit IPA -- it won't work on 32-bit devices.

The IPA file is also **unsigned.** You WILL need to sign the game yourself, either via a paid Apple Developer account ($99/year), a free Apple Developer account (only 3 sideloaded apps at once and weekly refresh), or sideloading apps (TrollStore, KSign, SideStore, SideInstaller etc.)
